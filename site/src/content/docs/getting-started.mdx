ShedOS ships as a single bootable ISO. Flash it to a USB stick, run the
installer, and reboot into a working Hyprland desktop with your
toolchain preinstalled.

## 1. Download

Grab the latest ISO and its SHA-256 from the [download page](/download).

## 2. Verify

```sh
sha256sum shedos-YYYY.MM.DD-x86_64.iso
```

The hash must match the one on the download page. If it doesn't, the
file is corrupted — do not boot it.

## 3. Flash

```sh
sudo dd if=shedos-YYYY.MM.DD-x86_64.iso of=/dev/sdX bs=4M status=progress conv=fsync
```

Ventoy, Rufus, and balenaEtcher also work.

<CalloutBox kind="warn">
`dd` will not ask for confirmation. Double-check the target device —
writing to the wrong disk wipes it.
</CalloutBox>

## 4. Install

Boot the USB from your firmware's boot menu. The installer walks you
through partitioning, user creation, and locale. ShedOS defaults are
pre-seeded.

## 5. First boot

Your git identity (name + email) is configured during install — the
installer's user page collects it alongside your account. The desktop
(Hyprland, waybar, mako, kitty) boots already themed and ready.
