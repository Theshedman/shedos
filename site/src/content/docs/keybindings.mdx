The `Super` key (the Windows/Command key on most keyboards) is the
ShedOS modifier. Every desktop shortcut starts there.

## Applications

| Keys | Action |
|---|---|
| `Super` + `Return` | Open a terminal (kitty) |
| `Super` + `Shift` + `Return` | Open a floating terminal |
| `Super` + `D` | App launcher (walker) |
| `Super` + `E` | Code editor (VS Code) |
| `Super` + `N` | File manager (nautilus) |
| `Super` + `A` | API client (Postman) |
| `Super` + `B` | Default web browser |
| `Super` + `C` | Clipboard history |
| `Super` + `Alt` + `K` | Show all keybindings (searchable menu) |

## Window management

| Keys | Action |
|---|---|
| `Super` + `Q` | Close the focused window |
| `Super` + `V` | Toggle floating |
| `Super` + `F` | Fullscreen |
| `Super` + `M` | Maximize |
| `Super` + `J` | Toggle split direction |
| `Super` + `P` | Pseudo-tile |

## Focus

| Keys | Action |
|---|---|
| `Super` + `←` / `H` | Focus left |
| `Super` + `→` / `L` | Focus right |
| `Super` + `↑` / `K` | Focus up |
| `Super` + `↓` / `Shift` + `J` | Focus down |

## Move windows

| Keys | Action |
|---|---|
| `Super` + `Shift` + `←` / `H` | Move window left |
| `Super` + `Shift` + `→` / `L` | Move window right |
| `Super` + `Shift` + `↑` / `K` | Move window up |
| `Super` + `Shift` + `↓` | Move window down |

## Resize

| Keys | Action |
|---|---|
| `Super` + `Ctrl` + `←` / `H` | Shrink horizontally |
| `Super` + `Ctrl` + `→` / `L` | Grow horizontally |
| `Super` + `Ctrl` + `↑` / `K` | Shrink vertically |
| `Super` + `Ctrl` + `↓` / `J` | Grow vertically |

## Workspaces

| Keys | Action |
|---|---|
| `Super` + `1`…`9`, `0` | Switch to workspace 1–10 |
| `Super` + `Shift` + `1`…`9`, `0` | Move window to workspace 1–10 |
| `Super` + `S` | Toggle scratchpad (magic workspace) |
| `Super` + `Shift` + `S` | Send window to scratchpad |
| `Super` + scroll up / down | Previous / next workspace |
| `Super` + drag mouse | Move window (left button) / resize (right button) |

## Screenshots & recording

| Keys | Action |
|---|---|
| `Print` | Screenshot a region (opens editor) |
| `Shift` + `Print` | Screenshot the full screen (opens editor) |
| `Super` + `Print` | Save a region to `~/Pictures/Screenshots/` |
| `Super` + `R` | Start screen recording |
| `Super` + `Shift` + `R` | Stop screen recording |
| `Super` + `Shift` + `P` | Color picker (eyedropper) |

## System

| Keys | Action |
|---|---|
| `Super` + `Escape` | Lock the screen |
| `Super` + `Shift` + `E` | Log out / shutdown menu |
| `Super` + `F9` | Toggle night-light (warm display) |

## Media & hardware keys

| Keys | Action |
|---|---|
| `Volume Up` / `Volume Down` | Volume ±5% |
| `Mute` | Toggle output mute |
| `Mic Mute` | Toggle microphone mute |
| `Brightness Up` / `Brightness Down` | Display brightness ±5% |
| `Play/Pause`, `Next`, `Previous` | Media control |
