The `Super` key (the Windows/Command key on most keyboards) is the
ShedOS modifier. Every desktop shortcut starts there. This page is
generated from the same metadata `shedman keybindings` reads — press
`Super` + `Alt` + `K` on a running system for the live, searchable version.

## Applications

| Keys | Action |
|---|---|
| `Super` + `Return` | Open a new terminal window |
| `Super` + `Shift` + `Return` | Open a terminal that floats above tiled windows |
| `Super` + `D` | Search and launch installed applications |
| `Super` + `E` | Open Visual Studio Code |
| `Super` + `N` | Open a new file manager window |
| `Super` + `A` | Open Postman |
| `Super` + `B` | Open the default web browser in a new window |
| `Super` + `C` | Browse and paste from clipboard history |
| `Super` + `Alt` + `J` | Open the ShedOS log viewer |
| `Super` + `Alt` + `K` | Show this keybindings dialog |
| `Super` + `Shift` + `U` | Review past system upgrades |
| `Super` + `Shift` + `P` | Pick a color from anywhere on the screen |

## Touchpad gestures

| Gesture | Action |
|---|---|
| 3-finger swipe horizontal | Slide between workspaces; carries any window held with Super+drag |
| 3-finger swipe up | Open the workspace grid |
| 3-finger swipe down | Close the workspace overview (opposite of 3-finger swipe up) |
| 3-finger pinch in | Toggle fullscreen on the active window |
| 3-finger pinch out | Toggle floating mode on the active window |
| 4-finger swipe left | Move the active window one workspace to the left |
| 4-finger swipe right | Move the active window one workspace to the right |
| 4-finger swipe up | Open the workspace grid (alternative to 3-finger swipe up) |
| 4-finger swipe down | Close the workspace overview (opposite of 4-finger swipe up) |
| 4-finger pinch in | Open the app launcher |
| 4-finger pinch out | Toggle the minimized special workspace to clear the screen |
| 2-finger pinch out | Magnify the area around the cursor (accessibility zoom) |
| 2-finger pinch in | Return the cursor area to normal magnification |
