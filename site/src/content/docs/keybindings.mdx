<h1 style="margin-top:.7rem;">Keybindings</h1>

<p>The <code>Super</code> key (the Windows/Command key on most keyboards) is the ShedOS modifier. Every desktop shortcut starts there. This page is generated from the same metadata <code>shedman keybindings</code> reads — press <kbd class="key">Super</kbd> + <kbd class="key">Alt</kbd> + <kbd class="key">K</kbd> on a running system for the live, searchable version.</p>
